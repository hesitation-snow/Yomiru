# Yomiru 部分源码

这里收录 Yomiru `1.5.0+12` 中不依赖站点接口的独立模块，供阅读、研究和复用。

## 公开范围

| 目录 | 内容 |
| --- | --- |
| `lib/reader/` | HTML 正文解析、Ruby 注音与脚注显示、排版设置、阅读位置、滚动布局索引和布局缓存 |
| `lib/widgets/` | 排版设置面板、滑动翻页手势、阅读时钟、列表续载与空状态组件 |
| `lib/services/` | 本地后台任务队列、倒计时、系统状态栏控制和音量键通道适配 |
| `lib/services/epub/` | 本地流式 ZIP 打包器；不包含章节获取或完整 EPUB 制作流程 |
| `test/` | 与上述公开模块对应的部分单元及组件测试 |

## 不包含的内容

- 站点接口地址、请求协议、登录鉴权、签名和网络请求实现。
- 站点响应模型、依赖接口的业务页面、内容下载与账号缓存逻辑。
- 服务端代码、部署配置、遥测、推送配置及签名密钥。
- 完整应用入口、Android/iOS 应用工程和安装包构建流程。

这是经过筛选的源码快照，不是完整客户端，也不是可直接运行的演示 App。安装包请从本仓库 Releases 获取。

## 检查与测试

验证使用 Flutter `3.47.0`。在本目录执行：

```sh
flutter pub get
flutter analyze
flutter test --concurrency=1
```

包名保留为 `yomiru`，便于沿用组件与测试中的导入路径；不会发布到 pub.dev。

`reader_volume_keys.dart` 仅包含 Flutter 侧的本地平台通道适配，实际音量键拦截需要宿主提供原生实现。简繁转换依赖相应 Flutter 插件；相关测试使用模拟平台通道。列表续载组件只调用宿主传入的回调，不实现任何站点请求。测试中的图片和链接均为示例数据。

## 更新与许可

公开目录按模块单独维护，不自动同步完整应用源码或提交历史。新增内容应先检查直接及间接依赖、字符串、注释和测试数据，避免引入接口实现或敏感配置。
